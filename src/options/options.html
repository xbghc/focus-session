Focus Session 设置

阅读记录只保存在本机的浏览器存储里。但划词翻译会把选中的文本及其所在段落发送给 MiniMax——不需要翻译的页面请加进下面的排除域名，或直接关掉划词翻译。

MiniMax（翻译与复习都用它）
上限不是花销，只有真生成的 token 才计费；压低只会把输出截断
流式下是整条流的总时限；实测 3–10 秒，长选区加讲解更久

去 platform.minimaxi.com 创建 API Key。密钥单独存放，不会随导出文件带出，也不会进入网页所在的进程。

划词翻译
关掉后文章页不再监听选区
短于此长度忽略，避免误选
只拦离谱的量：超过才先弹按钮确认，不自动发请求
随选中文本一起发出的段落，用于判断词义
除译文外再补一句用法；选中句子时逐个讲里面的生词

讲解会让一次整句翻译的输出 token 大约翻倍，浮层也要多一两秒才定住—— 译文仍然是最先到的那一个。只想要译文就关掉它。

读完判定

一篇文章要同时满足两个条件才算读完：已读比例达到下面的阈值， 且正文最后一段进入过视野。只看比例会把读了 80% 就关掉算成读完；只看触底会把 一路滚到底的跳读算成读完。

读完状态可在 dashboard 手动改
续读位置

记住每篇文章上次读到的段落，重新打开时跳回去。 只在网页自己没有定位过时才跳——链接带 #锚点、 或浏览器刷新时已经恢复了滚动位置，都说明落点已经有人安排了，插件不抢。 抽取正文期间你要是已经自己滚了，这次也不跳。

跳完左下角会给一行说明和「回到顶部」
文章回顾

读到上面的比例时，会把正文存下来并让 LLM 先生成一份大纲和三个回想问题， 等你读完最后那点，材料已经备好了。读两眼就走的页面不会被保存。

这是唯一无需你动手就会花 token 的地方
走神阈值

阅读本身不产生任何输入：一屏 400 词按 238 字/分要读 100 秒，期间可以一下都不动。 所以两个阈值都随视口里的文字量自适应——静默上限 = max(下面的固定值， 读完当前一屏所需时间 × 1.5)，再不超过自适应上限。固定值是下限，视口里没什么字 （图、评论区）时它照旧起作用。

完全没有活动信号多久算走神（下限）
有输入但滚动位置不变多久算发呆（下限）
静默上限最多放宽到这里；真离开时最多高估这么长。填 0 关闭自适应
短于此长度直接丢弃，过滤切换标签产生的碎片
段落已读判定

一段文字要在视野里停留到读完它所需时间的一定比例才记为已读， 不是露出一秒就算。正常阅读的停留是所需时间的 0.8 倍以上，跳读只有 0.4 倍左右， 默认 50% 落在两者之间。

按 238 词/分（英文）、400 字/分（中日韩）估算所需时间
阈值的下限：几个字的标题也得看上一眼
统计口径

session 的边界是「输入信号中断」，切去查个东西再回来、安静读一屏后被判走神， 都会把一次连续投入切成一串片段。回合把同一篇文章内间隔不长的片段接回去， 概览页以它为主。合并阈值本身是结果的一部分，概览页会把它写出来。

同一篇文章内间隔不超过这个值的片段合成一个回合

数据

导出为 JSON：一是给另一台设备（手机 App、另一台电脑上的扩展）导入合并，二是日后接入 ActivityWatch 之类的工具做跨应用统计。

导入按文章、专注片段、划词、复习卡逐条合并：同一份文件导两次不会重复， 同一个词在两边各有一张卡时合成一张、取最近复习过的排期。设置与 API Key 不受影响。

诊断日志

每次 LLM 调用失败（解析失败、超时、接口报错）都把现场记在本机：错误信息、模型的原始输出、 当时选中的文本。出问题时复制或下载它即可。不含 API Key，不进上面的数据导出，只留最近 10 条。
